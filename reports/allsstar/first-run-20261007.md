# ALLSSTAR Audio Delivery Experiment

The first real audio-only reading versus spontaneous baseline completed locally
on 7 October 2026. Five-fold evaluation with disjoint speakers achieved 0.739
balanced accuracy and 0.812 ROC AUC. Spontaneous speech was incorrectly labeled
reading in 27.9% of its windows, so this is a research baseline rather than an
interview-ready detector. Reading is not evidence of AI use.

## Data and processing

The user-provided `2982.zip` was moved, without overwriting an existing archive,
to `data/raw/allsstar/english-full.zip`. Downloads no longer holds the original.
The ZIP is 10,615,555,746 bytes (9.89 GiB). Its inventory contains 1,163 English
WAV files, 963 TextGrids and 140 speaker IDs, matching the requested English
corpus. All archive members passed CRC validation. The source is
[Northwestern ALLSSTAR](https://speechbox.linguistics.northwestern.edu/allsstar).

Only NWS, ST1 and ST2 were processed for this experiment. NWS labels reading;
ST1/ST2 label picture-story elicitation, treated as spontaneous speech. Labels
come from task definitions, not from judgments about fluency. TextGrids were
counted but not used for alignment or text features. Other tasks remain in the
ZIP; QNA requires speaker separation before use.

| Task | Selected recordings | Recordings with usable windows | Usable 30-second windows |
|---|---:|---:|---:|
| NWS reading | 140 | 134 | 148 |
| ST1 spontaneous | 139 | 136 | 331 |
| ST2 spontaneous | 139 | 138 | 383 |
| Total | 418 | 408 | 862 |

Each recording contributes at most its first four complete, nonoverlapping
30-second windows, converted temporarily to 16 kHz mono PCM. Short tails are
discarded. Ten recordings were shorter than one window; two additional windows
were silent or had no separable energy-based speech. Decode failures: zero.
Five retained windows were flagged noisy (one ST1, four ST2); none were flagged
clipped. These flags are separate from predictor inputs and were not exclusion
criteria. Human listening checks and VAD-boundary validation remain outstanding.

All 140 speakers have usable windows, but only 132 have both classes. Two have
reading only and six spontaneous only. More windows do not increase the number
of independent speakers. Feature, label, inventory and quality outputs total
1,407,210 bytes; no fully unpacked corpus is retained.

## Model and evaluation

The pipeline uses median imputation, standardization and class-balanced Logistic
Regression, with 14 timing/loudness features. It uses no ASR, transcript content,
pitch/F0, neural embeddings, task codes, identities, demographics or quality flags
as predictors. Missing pause and segment summary statistics are imputed inside
each training fold: mean/max pause duration 25 rows each, pause-duration standard
deviation 35 rows, segment-duration standard deviation 24 rows.

StratifiedGroupKFold uses five folds and seed 42, grouping by stable speaker ID.
Each fold has both classes and zero training/test speaker overlap. Held-out
balanced accuracy ranges from 0.659 to 0.806. No hyperparameter search or threshold
tuning was performed. The saved final pipeline is refitted on all 862 windows;
the metrics below instead use predictions from the held-out folds.

| Out-of-fold metric | Value |
|---|---:|
| Balanced accuracy | 0.7390 |
| Majority-class balanced accuracy | 0.5000 |
| Reading F1 | 0.4880 |
| ROC AUC | 0.8122 |
| Reading precision | 0.3601 |
| Reading recall | 0.7568 |
| Spontaneous windows incorrectly predicted reading | 199/714 (27.9%) |

Confusion matrix, with rows as actual classes and columns as predicted classes:

| Actual class | Predicted spontaneous | Predicted reading |
|---|---:|---:|
| Spontaneous | 515 | 199 |
| Reading | 36 | 112 |

The 148/714 class imbalance makes ordinary accuracy misleading: always predicting
spontaneous already gives 82.8% ordinary accuracy, but only 50% balanced accuracy.
Evaluation is window-level, not candidate-level. Correlated windows require
speaker-clustered uncertainty analysis; no confidence intervals are reported here.

## Local artifacts and reproduction

From the repository root:

```sh
.venv/bin/python -m interview_integrity.modeling.allsstar \
  --source data/raw/allsstar/english-full.zip \
  --out-dir data/processed/allsstar/delivery-first-run \
  --expect-wav 1163 --expect-textgrid 963 --expect-participants 140 \
  --tasks NWS ST1 ST2 --window-seconds 30 --max-windows 4 --workers 2

.venv/bin/python -m interview_integrity.modeling.audio_baseline \
  --features data/processed/allsstar/delivery-first-run/features.jsonl \
  --labels data/processed/allsstar/delivery-first-run/labels.csv \
  --out-dir data/models/allsstar-delivery-first-run \
  --folds 5 --seed 42
```

These output directories already exist; choose new names to rerun. The importer
and trainer refuse to overwrite previous runs. Local artifacts are
`features.jsonl`, `labels.csv`, `inventory.json`, `quality.json`, `model.pkl`
(2,309 bytes) and `metrics.json` (2,687 bytes). Reloading the trusted, locally
generated model and predicting sample feature rows succeeded. Never load an
untrusted pickle.

Environment: native macOS arm64, Python 3.13.7, NumPy 2.5.3, scikit-learn 1.9.1,
FFmpeg 9.0.2. No hosted processing, ASR run, raw-media upload, commit or push was
performed for this experiment. Raw media, per-speaker features and model artifacts
are excluded from Git; this aggregate report contains no recordings or private
download links.

## Interpretation and next checks

Speaker separation does not remove task confounding: reading a passage and
describing a picture differ in content, cognitive demands and recording protocol.
The model may learn those differences rather than general reading behavior.
Energy VAD is not diarization; leading silence and background sound can also
distort its features. Fixed windows and the first-120-second cap are engineering
choices, not validated optimal settings.

Inspect audio/VAD examples and noise flags before making model changes. Then test
held-out tasks with disjoint speakers and report participant-level results and
language-background slices. Consent-based technical-interview pilots remain
necessary for interview-domain transfer and actual AI-assisted/unassisted ground
truth. A person can read their own notes without AI, while an AI-assisted person
can paraphrase rather than read; this classifier cannot resolve either case.
