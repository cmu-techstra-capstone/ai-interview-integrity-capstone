# Desklib original-AI text stress test — 2026-10-22

## Result

Pinned model: `desklib/ai-text-detector-v1.01` at
`5fdea974cd4287c61674951ec78803aa274e2fb7`.

The model was evaluated locally on the previously frozen Beemo cohort. The
headline comparison is **original AI text vs. human text**. Expert-edited AI is
not used in the headline result because this project phase treats substantial
human rewriting as outside the target original/verbatim-AI condition.

| Metric | Result |
| --- | ---: |
| Common complete paired prompt groups | 103 / 200 (51.5%) |
| Original AI vs. human AUROC | **0.8705** |
| Paired bootstrap 95% interval | **0.8267–0.9133** |
| Within-prompt AI score higher than human | **92.2%** |
| Mean score, human | 0.6514 |
| Mean score, original AI | 0.9566 |

AUROC measures ranking separation and is not classification accuracy. No
threshold was selected, and the raw sigmoid score is not a calibrated
probability of interview AI assistance.

## Coverage

- Human: 113 / 200 scored; 84 too short and 3 over the common token limit.
- Original AI: 154 / 200 scored; 35 too short and 11 over the common token limit.
- The paired AUROC uses only the 103 prompt groups with complete human and
  original-AI inputs. Excluded examples were not replaced.

## Scope

This is a written-text stress test, not an interview, audio, ASR or cheating
validation. The model was trained on RAID; training overlap with every upstream
Beemo component cannot be completely audited. The result supports keeping
Desklib as a transcript-detector candidate for controlled interview pilots, not
deploying it as a hiring decision system.

Weights, source text, per-example outputs and private audio/transcripts remain
Git-ignored. The implementation reconstructs the published DeBERTa mean-pooling
head locally, loads the pinned safetensors state strictly and executes no remote
custom code.
